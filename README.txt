SKILLSPRING WEBSITE
===================

Files:
- index.html: Complete website (HTML, CSS and JavaScript are included in this file).

How to publish:
1. Extract this ZIP file.
2. Upload the index.html file (or the extracted folder) to a static website host.
3. Make sure the published homepage is named index.html.

Notes:
- This is a front-end demo website.
- The course search, category filters, FAQ toggles and pop-up forms work in the browser.
- The enquiry form currently displays a demo confirmation only. It does not send or store enquiries on a server.
- The website's original creator credit, Janvi, has been preserved.
